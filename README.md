# FIN 4210 学习网站

公司金融（Corporate Finance）期末复习站 —— 按主题组织，覆盖 Lecture 1–18 全部课件、Problem Set 1、期中练习卷及 2024 / 2025 两套期中真题详解。

## 在线访问

https://kikyuyu.github.io/fin4210-study-website/

## 目录结构

- `index.html` — 课程地图、考核结构、公式速查总表
- `part1-asset-pricing.html` — 资产定价：收益与风险、组合理论、CAL、CAPM、APT
- `part2-capital-structure.html` — 资本结构：MM 定理、税盾、财务困境、代理成本、优序融资
- `part3-payout-policy.html` — 分配政策：股利无关论、税收、信号模型
- `part4-capital-budgeting.html` — 资本预算与估值：增量现金流、WACC / APV / FTE
- `part5-governance-ma.html` — 公司治理与并购
- `part6-practice-exams.html` — 习题与真题详解（PS1、练习卷、2024/2025 期中）
- `assets/` — 样式与脚本

纯静态站点，无构建步骤；公式渲染走 MathJax CDN（jsDelivr，自动回退 unpkg / cdnjs）。
